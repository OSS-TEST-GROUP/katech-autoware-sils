# Source notices and scope

This repository references K-Autoware and Autoware Universe by immutable Git commits rather than republishing their complete source history. Preserve the LICENSE/NOTICE files from those repositories when building or redistributing them. Copied Autoware-derived source files retain their original copyright headers.

The source snapshots and trained models are published at the project owner's request. No AI Hub dataset, photographs, private C-Track geometry, cooked asset, PCD, authentication material, or Unreal Engine source is included in this Git repository. The model release contains inference ONNX files, not training datasets or device-specific engines.

This is a simulation/development candidate, not a safety-certified driving system. Publication does not establish HIL/real-vehicle validation. See README for incomplete integration items and model input/output contracts.
